## 1. Alignments & Animations

Supports all 9 `Alignment` presets plus custom `new Alignment(x, y)` coordinates in `[-1, 1]`:

- Top / bottom sheets: `Alignment.topCenter`, `Alignment.bottomCenter`
- Side drawers: `Alignment.centerLeft`, `Alignment.centerRight`
- Corner panels: `topLeft`, `topRight`, `bottomLeft`, `bottomRight`

Built-in `SmartAnimationType` options adapt smoothly to alignment (`centerScale_otherSlide`, `centerFade_otherSlide`, `scale`, `fade`), or supply `animationBuilder` for custom Web Animations API motion.

---

## 2. Pointer Penetrate & Mask Triggers (`usePenetrate` & `maskTriggerType`)

- **`usePenetrate: true`**: Transparent backdrop lets clicks and scrolling pass through to underlying UI.
- **`ignoreArea`**: Defines a click-through rectangle inside an otherwise blocking backdrop.
- **`config.custom.maskTriggerType`**: Fires mask dismiss on `up` (default), `down`, or `move`.

## 3. Native `<dialog>.showModal()` Top Layer (`useSystem`)

Set `useSystem: true` to promote the overlay into the browser Top Layer:
1. Bypasses every parent `overflow: hidden` or high `z-index` trap;
2. Inherits built-in keyboard Tab trapping and focus restoration on close;
3. Integrates natively with `Esc` and `backType`.

```ts
const submitted = await SmartDialog.show<{ email: string }>({
  useSystem: true,
  ariaLabel: 'Newsletter Settings',
  builder: ({ dismiss }) => subscriptionFormElement,
});
```

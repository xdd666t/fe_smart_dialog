## 1. Anchor Targets (`targetElement` vs `targetBuilder`)

- **Element Anchor**: Pass `targetElement` (or `targetContext`) as an `HTMLElement`, selector string, React/Vue `Ref`, or getter function.
- **Coordinate Anchor (`targetBuilder`)**: Return explicit viewport `new Offset(x, y)` coordinates (ideal for right-click context menus):

```ts
import { Alignment, Offset, SmartDialog } from 'fe-smart-dialog';

document.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  SmartDialog.showAttach({
    targetBuilder: () => new Offset(e.clientX, e.clientY),
    alignment: Alignment.bottomRight,
    builder: ({ dismiss }) => contextMenuElement,
  });
});
```

---

## 2. Edge Alignment & Auto Flip (`adjustBuilder`)

Configure `SmartDialog.config.attach.attachAlignmentType` (`outside` | `center` | `inside`) to align popover edges against the anchor rectangle.

Supply `adjustBuilder(param)` to inspect `selfOffset`, `selfSize`, `targetOffset`, and viewport dimensions and return `new AttachAdjustParam({ alignment, builder })` when flipping near edges; combine with `scalePointBuilder(selfSize)` to anchor zoom transforms to your arrow tip.

---

## 3. Onboarding Spotlight Cutouts (`highlightBuilder`)

Return a `HighlightRegion` (`SmartHighlightShape.rect` or `SmartHighlightShape.circle`) from `highlightBuilder` to carve an SVG `evenodd` spotlight aperture directly through the dimmed backdrop:

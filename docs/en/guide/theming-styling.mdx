# Theming, Dark Mode & CSS Variables

Built-in Toast, Loading, and Notify widgets ship with scoped CSS powered by `--fsd-*` custom properties, so you can re-skin overlays globally or per container without touching JavaScript builders.

## 1. Light & Dark Mode (`SmartTheme`)

Switch appearance globally at initialization or dynamically when your app toggles theme:

- `SmartTheme.auto` (default): tracks `prefers-color-scheme: dark` as well as common `.dark` / `[data-theme="dark"]` root attributes.
- `SmartTheme.light`: forces light built-in surfaces.
- `SmartTheme.dark`: forces dark built-in surfaces.

```ts
import { SmartDialog, SmartTheme } from 'fe-smart-dialog';

SmartDialog.init({ theme: SmartTheme.dark });
```

## 3. Custom Global Template Factories

Override default Toast, Loading, Notify, or wrap every Custom dialog through `SmartDialog.init()`:

```ts
import { SmartDialog, SmartNotifyStyle, html } from 'fe-smart-dialog';

SmartDialog.init({
  toastBuilder: (msg) => html`<div class="my-toast">${msg}</div>`,
  loadingBuilder: (msg) => html`<div class="my-spinner">${msg}</div>`,
  notifyStyle: new SmartNotifyStyle({
    successBuilder: (msg) => html`<div class="banner ok">${msg}</div>`,
  }),
  styleBuilder: (child) => {
    const shell = document.createElement('section');
    shell.className = 'brand-shell';
    shell.appendChild(child);
    return shell;
  },
});
```

## 4. Micro-Frontend Container Scoping

Mount all 5 layers inside a dedicated DOM subtree with custom `zIndexBase`:

```ts
SmartDialog.init({
  container: '#micro-app-root',
  zIndexBase: 20000,
});
```

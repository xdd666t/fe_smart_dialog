# 主题适配、CSS 变量与容器隔离

`fe-smart-dialog` 的内置 Toast、Loading 与 Notify 组件全部采用原生 **Scoped CSS** 与 **`--fsd-*` CSS 变量** 构建，无需引入 Tailwind 即可轻松换肤与适配深浅色模式。

## 1. 浅色 / 深色模式 (`SmartTheme`)

通过 `SmartDialog.init({ theme })` 切换主题策略（也可以在你的站点主题切换器里动态再次调用 `SmartDialog.init({ theme })`）：

- `SmartTheme.auto`（默认）：根据系统 `prefers-color-scheme: dark` 以及常见根节点标记（如 `.dark`、`[data-theme="dark"]`）自动识别明暗主题。
- `SmartTheme.light`：强制使用浅色内置组件外观。
- `SmartTheme.dark`：强制使用深色内置组件外观。

## 3. 全局自定义 UI 工厂 (`init` builders)

如果你希望完全替换默认 Toast、Loading、Notify 甚至所有弹窗外框，在 `SmartDialog.init()`（或 `<SmartDialogProvider>`）中传入全局构造器即可：

```ts
import { SmartDialog, SmartNotifyStyle, html } from 'fe-smart-dialog';

SmartDialog.init({
  toastBuilder: (msg) => html`<div class="my-toast">${msg}</div>`,
  loadingBuilder: (msg) => html`<div class="my-spinner">${msg}</div>`,
  notifyStyle: new SmartNotifyStyle({
    successBuilder: (msg) => html`<div class="banner ok">${msg}</div>`,
    errorBuilder: (msg) => html`<div class="banner err">${msg}</div>`,
  }),
  // 类似 Flutter SmartInitType.custom 统一包裹每层 Custom Dialog
  styleBuilder: (child) => {
    const wrapper = document.createElement('section');
    wrapper.className = 'brand-dialog-shell';
    wrapper.appendChild(child);
    return wrapper;
  },
});
```

## 4. 微前端 / 多实例容器与层级控制

在 qiankun、iframe 或嵌套预览窗口内使用时，可通过 `container` 将 5 层容器限制到指定 DOM 节点内部，同时自定义 `zIndexBase`：

```ts
SmartDialog.init({
  container: '#sub-app-root', // CSS 选择器或 HTMLElement
  zIndexBase: 20000,          // 默认为 9999
});
```

# Attach 锚点定位与聚光灯引导

`SmartDialog.showAttach(options)` 专为气泡提示、下拉菜单、上下文右键菜单与多步新手引导而生：它能精准测量目标元素位置，沿边缘自动对齐，配合 SVG `evenodd` 实现顺滑的区域挖空聚光灯。

## 1. 目标指定方式 (`targetElement` vs `targetBuilder`)

- **绑定已有元素**：传入 `targetElement`（或 `targetContext`），支持 `HTMLElement`、CSS 选择器、React/Vue `Ref` 或返回元素的 getter 函数。
- **任意坐标锚点 (`targetBuilder`)**：在右键菜单或屏幕角落悬浮场景，无需真实锚点 DOM，直接计算返回视口坐标 `new Offset(x, y)` 即可：

```ts
import { Alignment, Offset, SmartDialog } from 'fe-smart-dialog';

document.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  SmartDialog.showAttach({
    targetBuilder: () => new Offset(e.clientX, e.clientY),
    alignment: Alignment.bottomRight,
    builder: ({ dismiss }) => contextMenuElement,
  });
});
```

---

## 2. 边界对齐与视口自适应翻转 (`adjustBuilder`)

在全局配置中配合 `SmartDialog.config.attach.attachAlignmentType` 可切换相对目标边框的对齐锚线：`outside`（外缘对齐）、`center`（居中）或 `inside`（内缘对齐）。

如果气泡靠近屏幕边界容易被裁切，实现 `adjustBuilder(attachParam)` 即可根据 `selfOffset`、`selfSize`、`targetOffset` 和 `window.innerHeight` 返回新的 `new AttachAdjustParam({ alignment, builder })` 自动翻转方向；搭配 `scalePointBuilder(selfSize)` 还能把缩放入场原点精确锁定在气泡箭头尖端！

---

## 3. 新手引导聚光灯 (`highlightBuilder`)

`highlightBuilder(targetOffset, targetSize)` 只需返回一个 `HighlightRegion`（矩形或圆形坐标描述），内核自动生成 SVG `fill-rule="evenodd"` 遮罩，完美高亮目标控件，甚至支持引导步骤接力：

## 1. 对齐定位与动画 (`Alignment` & `SmartAnimationType`)

支持完整的 9 个标准方位常量以及 `new Alignment(x, y)` 任意归一化坐标（`x, y ∈ [-1, 1]`）：

- 顶部 / 底部抽屉：`Alignment.topCenter` / `Alignment.bottomCenter`
- 左右侧边栏：`Alignment.centerLeft` / `Alignment.centerRight`
- 四角浮窗：`topLeft` / `topRight` / `bottomLeft` / `bottomRight`

四种内置动画 `SmartAnimationType` 会随方位智能切换滑入方向：
- `centerScale_otherSlide`（默认）：居中时弹性缩放，贴边时从对应边缘平滑滑入。
- `centerFade_otherSlide`：居中淡入淡出，贴边从对应边缘滑入。
- `scale` / `fade`：全方位统一缩放或淡入淡出。

你也可以传入 `animationBuilder` 完全接管 Web Animations API / CSS 动效：

```ts
SmartDialog.show({
  animationTime: Duration.milliseconds(260),
  animationBuilder: (_controller, child, animationParam) => {
    animationParam.onForward = () => {
      child.animate(
        [{ opacity: 0, transform: 'translateY(16px)' }, { opacity: 1, transform: 'none' }],
        { duration: animationParam.animationTime, fill: 'forwards' },
      );
    };
    animationParam.onDismiss = () => {
      child.animate(
        [{ opacity: 1 }, { opacity: 0, transform: 'translateY(16px)' }],
        { duration: animationParam.animationTime, fill: 'forwards' },
      );
    };
    return child;
  },
  builder: ...
});
```

## 2. 穿透交互与遮罩定制 (`usePenetrate` & `maskTriggerType`)

- **`usePenetrate: true`**：遮罩层本身设置为透明不拦截点击，底层页面的列表滚动与按钮点击完全正常响应。
- **`ignoreArea`**：即使在非穿透遮罩模式下，也可以挖出可点击透传的安全矩形。
- **`config.custom.maskTriggerType`**：精确决定点击遮罩是在 `up`（松手，默认）、`down`（按下瞬间）还是 `move` 时触发关闭。

## 3. 原生顶层 `<dialog>.showModal()` 模式 (`useSystem`)

设置 `useSystem: true` 后，弹窗内容将被托管至浏览器原生的 `<dialog>` Top Layer，拥有以下优势：
1. **彻底穿透任意局部 `z-index` 与 `overflow: hidden`**，永远处于浏览器视口最顶层；
2. 原生支持 `Tab` 焦点锁定与关闭后焦点自动回溯到触发按钮；
3. 原生支持 `Esc` 键关闭（并与 `backType` 集成）。

```ts
const submitted = await SmartDialog.show<{ email: string }>({
  useSystem: true,
  ariaLabel: '订阅设置',
  builder: ({ dismiss }) => subscriptionFormElement,
});
```
